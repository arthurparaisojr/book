Book Admin

Acesso administrativo do projeto Book

Este painel Angular concentra login, operacao de catalogo e validacao das regras principais da API `.NET 8`.

Fluxo recomendado

  • entre com um usuario local de desenvolvimento;
  • consulte livros, autores e assuntos;
  • grave dados com token JWT e policy de `Admin`.

Perfis locais

`book-admin` grava no catalogo. `book-reader` navega, mas recebe `403` em operacoes de escrita.
