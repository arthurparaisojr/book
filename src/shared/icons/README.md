# Icons

Biblioteca oficial de icones do projeto `Book`.

## Estrutura

- `svg/`: arquivos SVG compartilhados entre Angular e React.

## Regra

- sempre que um novo icone for necessario, o nome do arquivo deve ser informado antes;
- o local oficial de gravacao e `src/shared/icons/svg/`;
- prefira nomes autoexplicativos e orientados a funcionalidade.

## Exemplos de nome

- `book-menu-livros.svg`
- `book-action-salvar.svg`
- `book-report-autor.svg`
