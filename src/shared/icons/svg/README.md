# SVG

Armazene aqui os icones SVG oficiais do projeto.

## Local oficial

`src/shared/icons/svg/`

## Convencao

- usar prefixo `book-`;
- usar nomes descritivos;
- evitar nomes genericos como `icon1.svg` ou `novo.svg`.

## Quando pedir um SVG

Se algum SVG precisar ser fornecido externamente, a solicitacao deve informar:

- nome exato do arquivo;
- finalidade do icone;
- caminho de gravacao neste diretorio.

## SVG atual do app

- `book-nav-dashboard.svg`: icone do menu de dashboard.
- `book-nav-livros.svg`: icone do menu de livros.
