# Checklist de Entrega 6.B

## Objetivo

Conferir se a etapa `6.B` esta pronta antes de avancar para a validacao final da
etapa `6.C`.

## 1. Scripts operacionais

- `start-infra.sh` documentado
- `start-fullstack.sh` documentado
- `stop-fullstack.sh` documentado
- `reset-fullstack.sh` documentado
- `apply-database.sh` documentado
- `validate-database.sh` documentado
- `export-openapi.sh` documentado
- `prepare-delivery-artifacts.sh` documentado

## 2. Artefatos de API

- `artifacts/api/book-api-openapi-v1.json` gerado
- `artifacts/api/README.md` atualizado
- rotas principais conferidas no Swagger

## 3. Artefatos de banco

- `artifacts/database/relatorio-detalhado-banco.md` atualizado
- `artifacts/database/checklist-validacao-banco.md` atualizado
- `artifacts/database/validacao-banco-output.txt` gerado quando o banco estiver ativo

## 4. Artefatos de apresentacao

- `artifacts/reports/roteiro-apresentacao-tecnica.md` atualizado
- `artifacts/reports/checklist-entrega-6b.md` atualizado
- referencias de acesso local conferidas

## 5. Documentacao

- `README.md` atualizado
- `docs/setup/README.md` atualizado
- `docker/README.md` atualizado
- `scripts/README.md` atualizado

## 6. Critrio para avancar

A etapa `6.B` pode ser considerada pronta quando:

- a stack completa sobe do zero;
- os scripts de operacao estao claros;
- o OpenAPI pode ser exportado;
- os artefatos de banco e apresentacao estao preenchidos;
- o roteiro de demonstracao esta pronto para uso.
