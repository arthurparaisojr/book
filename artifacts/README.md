# Artifacts

Esta pasta guarda evidencias e materiais gerados para apresentacao, homologacao e
comprovacao tecnica.

## Subpastas

- `api/`: export de OpenAPI, colecoes e exemplos.
- `database/`: relatorios de banco, dicionario de dados e evidencias de execucao.
- `diagrams/`: diagramas exportados, incluindo materiais para apresentacao.
- `reports/`: relatorios gerados pela aplicacao.

O conteudo desta pasta complementa a documentacao de `docs/` e nao substitui scripts
fonte versionados.
