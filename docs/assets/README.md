# Assets

Esta pasta guarda arquivos de apoio usados na documentacao.

## Regras

- diagramas e imagens devem ter nome objetivo;
- arquivos usados pelo `README.md` principal devem ficar aqui;
- nao use esta pasta para artefatos gerados em apresentacao ou exportacao final;
- para evidencias, use `artifacts/`.

## Estrutura

- `images/`: imagens fonte da documentacao, incluindo o modelo de dados.
