# Documentacao

Esta pasta concentra a documentacao funcional, tecnica e operacional do projeto.

## Conteudo

- `architecture/`: arquitetura, camadas, responsabilidades e tecnologias.
- `api/`: padrao da API, contratos, versionamento e tratamento de erros.
- `assets/`: imagens, referencias visuais e arquivos usados na documentacao.
- `backlog/`: etapas oficiais, entregas por fase e critrios de aceite.
- `database/`: relatorio detalhado do banco, regras, objetos e convencoes.
- `process/`: Git, commits, merge, rebase, revisao e governanca.
- `setup/`: passo a passo completo para criar a solucao do zero.

Use esta pasta como ponto de entrada para onboardings, apresentacoes e padronizacao do
time.
